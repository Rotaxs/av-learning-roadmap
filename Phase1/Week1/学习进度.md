## 待口述验证

Q3 口述验证（本次已通过）：

- 数据流：文件 → main 获取文件名 → `analyze_file` 读取并统计 → 以 `Stats` 结构体按值返回 → main 输出 `bytes/lines/words`。与 `main.cpp`/`stats.cpp` 及 README 处理流程一致。
- 资源所有权：`ifstream` 由 `analyze_file` 拥有，函数返回时作用域结束自动释放（RAII），无需手动 close。与 README“文件流对象拥有文件资源，离开作用域时释放”一致。
- 设计取舍：拆分 `core` 库使统计逻辑可被其他模块复用、可单独测试；代价是增加一次编译链接与需要公开接口。与 CMakeLists 中 `core` STATIC target 结构一致。
