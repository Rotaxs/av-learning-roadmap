# Linux 命令基础

## `stdout` 和 `stderr`

一般来说，像是 `ls`，`cat` 这样的命令会将输出直接显示在控制台，这个输出就是 `stdout`

同样，默认的错误也会输出到控制台，这个错误信息就是 `stderr`

### 重定向 `stdout` 和 `stderr`

仅重定向 `stdout`，直接使用 `1>` 即可

`1` 表示 `stdout`（`0` 表示 `stdin`，`2` 表示 `stderr`）

```bash
ls -alh 1> out.txt
ls -alh > out.txt # 也可以省略 1
```

如果没有报错，输出信息会输出到文件 `out.txt` 中

而如果命令报错，报错信息不会写入文件，而如果我们想获取报错信息，需要使用 `2>`

```bash
ls path/not/exist 2> err.txt
```

下面这个可以将所有的信息重定向

```bash
ls &> all.txt
```

也可以这样写

```bash
ls > all.txt 2>&1
```

如果我们想隐藏报错信息，可以将 `stderr` 重定向到 `/dev/null`，这是 Linux 系统中的“黑洞”文件，所有写入其中的数据都会被清除

表示让 `stdout` 指向 `all.txt`，让 `stderr` 指向 `stdout` 指向的位置

### 退出码

使用 `echo $?` 可以查看上一条命令执行后的退出码

如果退出码为 `0`，表示没有错误，反之则是有错误

## 权限控制 `chmod`

### Linux 对象和权限类型

Linux 权限分为三类对象

| 对象类型 | 代码 | 说明 |
|:---:|:---|:---:|
| User | `u` | 文件所有者 |
| Group | `g` | 文件所属用户组 |
| Other | `o` | 其他用户 |
| All | `a` | 所有用户 |

和三类权限类型

| 权限类型 | 代码 | 八进制数值 | 对文件的作用 |
|:---:|:---:|:---:|:---:|
| Read | `r` | `4` | 查看内容 |
| Write | `w` | `2` | 修改内容 |
| Execute | `x` | `1` | 执行程序 |

通过将八进制数值组合相加，可以得到组合模式

- 7(4 + 2 + 1) : 读 + 写 + 执行
- 6(4 + 2 + 0) : 读 + 写
- 5(4 + 0 + 1) : 读 + 执行
- 4(0 + 2 + 1) : 写 + 执行

### 设置权限

#### 数字模式

通过三个八进制数分别设置三类对象（`u`/`g`/`o`）的权限

```bash
# 所有者可读写执行，组用户和其他人可读可执行（常用可执行文件/目录设置）
chmod 755 script.sh

# 所有者可读写，组用户和其他人仅可读（常用普通文件设置）
chmod 644 document.txt

# 赋予所有人完全控制权限（慎用，有安全风险）
chmod 777 public_folder
```

#### 符号模式

通过 `+`/`-` 添加或删除权限

```bash
# 为文件所有者增加执行权限
chmod u+x script.sh

# 移除其他人写权限
chmod o-w file.txt

# 为所有用户（a）统一赋予可读权限
chmod a+r document.txt

# 组合操作：所有者加执行，其他人减写
chmod u+x,g-w,o-w script.sh
```

#### 递归修改

`-R` 表示递归修改当前目录所有子目录和文件的权限

```bash
chmod -R 755 /path/to/directory
```
